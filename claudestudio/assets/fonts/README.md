# Fonts

All SIL Open Font License 1.1 (OFL.txt; each family's copyright is in its font
file), from github.com/google/fonts (`ofl/<family>`), variable-weight where the
family has it, converted to WOFF2 with fontTools.

| File | Family | Used for |
|---|---|---|
| Arimo.woff2 | Arimo | Enum.Font.Legacy, Arial, ArialBold, Arimo (Roblox maps Legacy and Arial to Arimo) |
| SourceSans3.woff2 | Source Sans 3 | SourceSans* |
| Montserrat.woff2 | Montserrat | Gotham* (Roblox maps Gotham to Montserrat), Montserrat |
| PressStart2P.woff2 | Press Start 2P | Arcade |
| Fredoka.woff2 | Fredoka | FredokaOne (Fredoka is its OFL successor) |
| Roboto.woff2 | Roboto | Roboto |
| Nunito.woff2 | Nunito | Nunito, and BuilderSans* (Builder Sans isn't open; Nunito is the stand-in) |
| Oswald.woff2 | Oswald | Oswald |
| Bangers.woff2 | Bangers | Bangers |

Any other Enum.Font falls back to Arimo.
