# AnyPS5 and the PS5 jailbreak (researched 2026-10-08)

These are two separate things that get mixed together in the news.

## AnyPS5: PS5 executables as native PC programs

- **What:** a static relinker, not an emulator.
  - It takes a decrypted PS5 game ELF and rewrites it as a native Linux ELF or Windows PE.
  - It reimplements Sony's system libraries (`libc`, `libkernel`, `libSce*` PRX modules) for the rewritten game to link against.
  - It recompiles the game's shaders to SPIR-V for Vulkan.

  This works because the PS5's CPU is x86-64 (AMD Zen 2), so the game's machine code runs on a PC unchanged. Only the OS and GPU layers need replacing.
- **Repo:** https://github.com/boykopovar/AnyPS5 (GPL-2.0 only). About 12.4k stars and 940 forks when I fetched the page; it has been on GitHub since 2026-08-03.
- **Ships nothing of Sony's:** no firmware, keys, libraries or games. You supply a decrypted executable from a game you own.
- **Status:**
  - One article reports v0.1.0 and v0.1.1 released on 2026-09-28. Another says there was no public release as of the same date. The repo page I fetched showed no releases. **Unconfirmed.**
  - Verified playable: Dreaming Sarah (a 2D indie platformer), 60 fps on a GTX 1050 Ti with an i5-7500.
  - A commercial game was demoed reaching its menu and crashing around frame 168, most likely from missing library functions (that diagnosis is the article's guess).
- **Limits:** a demanding game is still GPU-bound. Every system function a game calls has to be reimplemented. It's far behind shadPS4 (the PS4 emulator) in maturity.

## Relapse: the jailbreak that supplies the decrypted executables

- Published on GitHub as Relapse-Exploit (author reported as Nathan Fargo) around 2026-09-29.
- **How it works:** a browser stage (a JavaScript engine bug) followed by a kernel stage (a use-after-free). It's tethered: you re-run it after every reboot.
- **Coverage:** reported as firmware 7.00–13.60, on both PS5 and PS5 Pro. Firmware 14.00 (current as of late September) is not covered. Claims of a withheld 14.00 exploit are unconfirmed.
- **Risks:** PSN bans, and in principle bricking a console.

## What it means for us

- **Is "every game's code will be dumped" right?** Close. Any PS5 on firmware 13.60 or earlier can dump the games it owns, and AnyPS5 turns those dumps into PC programs. Newer games that require 14.00+ are out of reach for now.
- **For rebuilding:** AnyPS5 does the opposite of what we do. It keeps the game's original machine code and swaps the platform underneath it. We rebuild the behaviour itself. But a working AnyPS5 port gives us exactly what Quake needed: an **oracle**, the real game running on a PC, where we can instrument it, step it and compare tick by tick while we rebuild a system such as physics, movement or AI.
- **Fits our rules (RESEARCH.md §3):** a game the user bought, dumped from a console they have access to.
